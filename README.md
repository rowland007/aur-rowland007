# aur-rowland007

My personal collection of PKGBUILDs and custom package modifications.
Packages in this repo are named with the `-rowland007` suffix to avoid conflicts.

## Installation
1. Clone locally: `git clone https://github.com/rowland007/aur-rowland007.git ~/.local/share/aur-rowland007`
2. Update `~/.config/yay/config.json`: `"AURRepo": "/home/rowland007/.local/share/aur-rowland007"`
3. Run `git pull` occasionally to sync changes.
4. Install via `yay -S package-name-rowland007`.
